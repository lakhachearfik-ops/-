# أذكاري

موقع عربي بسيط لأذكار الصباح والمساء، جاهز للنشر على GitHub Pages.

## الملفات
- index.html
- style.css
- script.js

## التشغيل
افتح index.html في المتصفح.

## GitHub Pages
ارفع الملفات الثلاثة إلى مستودع GitHub عام، ثم:
Settings → Pages → Deploy from a branch → اختر main و /root → Save.

## ملاحظة المحتوى
تم تنظيم مجموعة أولية من الأذكار اعتمادًا على مصادر إسلامية، ومنها صفحة أذكار الصباح في موقع Islambook:
https://www.islambook.com/azkar/1/أذكار-الصباح

قبل نشر الموقع كمصدر ديني، راجع النصوص والتخريج مع مصدر موثوق.
